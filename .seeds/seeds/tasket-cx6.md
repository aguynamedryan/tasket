# Prior art: no existing tool combines project rows, priority order, blockers and fixed dates

Ryan asked on 2026-11-18 whether a system like this already exists. Two web searches found pieces, but no tool with all of them:

- TeuxDeux (https://teuxdeux.com/) and Tweek (https://tweek.helpscoutdocs.com/article/124-how-to-add-more-someday-columns) roll unfinished tasks to the next day. Their columns are days, not project rows. They have no blockers.
- Sunsama (https://help.sunsama.com/docs/getting-started/basics/task-rollover-and-recurring-tasks-the-basics) and Week Plan (https://weekplan.net/features/rolling-over-uncompleted-tasks/) roll tasks forward, but they are heavy daily planners.
- Notion can move dependent dates (https://www.simonesmerilli.com/business/notion-date-dependencies), but it needs real dates and much setup.
- A ClickUp feature request asks for the whole schedule to move forward a day (https://feedback.clickup.com/feature-requests/p/rollover-function-for-whole-tasks-tree-for-folders-and-lists). Nothing showed that it shipped.

The rollover features no longer matter, because Ryan later ruled that tasket has no days. See \[[tasket-lmj]\].
